这一段是整篇文章的核心。市面上叫法乱七八糟，"老号""耐用号""二解号""千粉号""商城号"满天飞，新手很容易被名词唬住。下面把目前主流的几种类型拆给你看。

**1. 老号（Aged Account）**

注册时间在半年到数年以上的个人号，最大的卖点就是"年份"这个属性。注册越久，平台信任度越高，被封概率越低。适合做广告投放、社群运营、长期养号矩阵。

**2. 耐用号（Durable Account）**

耐用号不等于老号，但两者经常重叠。耐用号指的是经过长时间养号、登录稳定、不易被退登或锁定的账号，通常注册时长两年以上，已经过了Facebook的"重点观察期"。这类号适合长期跑广告、做品牌矩阵。

**3. 二解号 / 三解号**

被封过然后申诉解封的账号，"二解"指二次解封，"三解"指三次解封。这类号在跨境圈其实挺受欢迎——能解封说明账号本身权重还在，平台认可它的真实性，反而是经过"实战检验"的号。但风险也明显：再封一次基本就回不来了。

**4. 商城号（Marketplace Account）**

开通了Facebook Marketplace（二手市集）功能的账号，可以在平台上直接上架产品、让客户下单付款，不用跳转第三方。海外本土电商、无货源电商、Shopee/Lazada引流的人最吃这一类。

**5. 千粉号 / 粉丝号**

带1000至9999粉丝的账号或主页，适合小额广告投放、社群运营、品牌背书。粉丝越多价格越贵，但要注意区分"真人粉"和"僵尸粉"——便宜的千粉号很多是机器刷的，互动率低到感人。

**6. 广告号 / 账单号**

已经有过广告投放历史的账号，自带广告账户和消费记录。买这种号的好处是省去了从零开户、过审的麻烦，直接就能跑广告。坏处是历史账单里有没有违规记录得自己查清楚。

**7. BM号（Business Manager号）**

带企业管理平台权限的账号，适合大规模广告投放和团队协作。BM号又分新BM、老BM、限额BM（如限额250、限额1500等），价格差距非常大。
